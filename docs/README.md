## Directory conventions

- `scripts/` contains repository generation and maintenance commands.
- `tools/` contains standalone firmware/protocol investigation utilities.
- `docs/site/` is the publishable Pages site. Its JSON data is generated by
  `scripts/generate_api_site.py`; the HTML, CSS, and JavaScript shell is authored.
- `firmware-analysis/metadata/` contains small, curated evidence. Extracted firmware,
  decompiler workspaces, original firmware archives, runtime state, and builds are
  intentionally ignored.
